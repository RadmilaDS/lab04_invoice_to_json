# lab04_invoice_to_json
This lab compares two methods for extracting JSON data from 48 scanned invoices in Kazakh, Russian, and English: traditional OCR (Tesseract) and a vision-language model (Qwen2-VL-2B). It evaluates their accuracy on clean and degraded images, identifies common errors, and compares how well each method recognizes text, numbers, and document fields
